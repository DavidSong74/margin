## YYYY-MM-DD - FlatList `renderItem` optimization pattern
**Learning:** Found multiple instances where FlatList `renderItem` was defining inline arrow functions (`renderItem={({ item }) => <Component />}`). This creates a new function reference on every render of the parent component, defeating `FlatList` internal optimizations and potentially triggering re-renders of all list items if `data` or other state changes. The codebase guidelines explicitly require: "When optimizing React Native `FlatList` components, always extract list items into separate components wrapped in `React.memo()` and use `useCallback` for the `renderItem` function and related event handlers."
**Action:** Today I will fix the `renderItem` prop in `artifacts/margin/app/(tabs)/feed.tsx` to use `useCallback` to maintain stable object references and prevent unnecessary list re-renders. (Note: other files like `search.tsx` already use `useCallback`, but `feed.tsx`, `InboxOverlay.tsx`, and `CommentsSheet.tsx` don't).
