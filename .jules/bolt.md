## 2024-03-24 - React Native FlatList Performance\n**Learning:** React Native FlatList `renderItem` functions defined inline without memoization cause unnecessary re-renders of all list items when parent state changes (like scroll events or input changes). Wrapping extracted components in `React.memo` and using `useCallback` for `renderItem` significantly reduces bridge traffic and JS thread load.\n**Action:** Always extract `FlatList` items into separate `React.memo()` components and `useCallback` for the `renderItem` function.
